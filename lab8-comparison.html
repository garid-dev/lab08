Лаборатори 8 — CSS framework-ийн харьцуулалт

Ижил найман карттай хуудсыг Bootstrap CDN болон Tailwind CSS CLI ашиглан бүтээв. Файлын хэмжээ нь шахаагүй байтын хэмжээс; Bootstrap-д CDN-ийн CSS дээр тухайн хуудсын CSS-ийг нэмсэн. Зураг, JavaScript болон бусад runtime хүсэлтийг CSS хэмжээнд оруулаагүй.

Дүгнэлт. Энэ хэмжилтээр Tailwind-ийн production CSS 13,021 байт, харин Bootstrap-ийн CDN болон хуудасны CSS нийлээд 233,211 байт байв; Bootstrap card гаднах элементийн class цөөн (3, Tailwind 6). Accessibility, Best Practices, SEO оноо ижил гарсан бол Lighthouse Performance энэ run-д Bootstrap-д 36, Tailwind-д 70 байлаа. Tailwind-ийн CSS хэмжээ бага бөгөөд энэ удаагийн Performance оноо өндөр гарсан ч хоёр хуудсанд ижил гаднын зургууд, видео, map iframe ашигласан тул оноог олон run-ийн дундажгүйгээр framework-ийн шууд нөлөө гэж үзэж болохгүй.

Card class тоо нь зөвхөн гаднах <article>-ийн class токеныг тоолсон. Хуудас тус бүрт Lighthouse 12.8.2-оор Microsoft Edge Chromium дээр 2026-10-26-нд нэг audit run хийсэн. Оноо сүлжээ болон төхөөрөмжөөс хамаарч хэлбэлзэнэ; Bootstrap CDN-ийн шахалттай дамжуулах хэмжээ энэ хүснэгтэд тооцоогүй.
